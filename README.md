# Deloitte Data Analytics & Forensic Technology Job Simulation 📊

## Executive Summary
Completed a virtual job simulation with **Deloitte** on Forage, focusing on data analysis and technology consulting. Analyzed real-world machine data for the **Daikibo Group** to spot equipment risks, find causes of factory downtime, and help improve machine maintenance.

## Tools & Methodology
- **Data Analytics & Visualization:** Power BI (DAX, Interactive Dashboards, Visual Cards, and Slicers)
- **Methodology:** Data Cleaning, Telemetry Analysis, Risk Identification, and Equipment Failure Tracking

## Key Findings & Deliverables
- **IoT Data Analysis:** Processed and analyzed over **160,000 machine logs** across global factory locations.
- **Downtime Root Cause:** Found **1,030 total minutes of line downtime** and identified the **Laser Welder in Osaka** as the biggest risk factor.
- **Factory Performance:** Tracked and compared downtime across major factory sites in Seiko, Shenzhen, Meiyo, and Berlin.
- **Equipment Breakdowns:** Grouped machine failures by type (e.g., 480 Laser Welder failures, 430 Laser Cutter failures) to help teams plan better maintenance schedules.
